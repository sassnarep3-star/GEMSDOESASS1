Scientific interpretation

Why might B2 have performed well?

In the audited owner mirrors, the GEMSDOE25 D2.8 mask has 44,090 dots. Removing pixels within two raster pixels of the known-label mirror yields the 37,654-dot GEMSDOE32 B2 mask exactly. GEMSDOE36’s historical mask contains all B2 dots plus 1,200 more. These are pixel comparisons, not authenticated upload records.

The official distance-weighted Tversky metric uses the best nearby prediction for each truth pixel and penalizes false-positive mass. More widely spaced dots or pruning some low-credit mass could improve the balance between coverage and precision. But pruning may also remove true faults: DrivenData staff say the known-fault mask is pixel-exact and new truth can be nearby. Without hidden truth and receipts, the causal explanation is not known.

Prospective methods should seek independent evidence of genuinely missing faults, not just copy or perturb an old map. See the ranked research slate →

Submission guide

How a future cleared file is submitted

These instructions are conditional. The current status is NO FILE CLEARED; none of the research links is an upload recommendation.

01

Wait for an eligible, unique candidate

The run must pass every feature-only leakage canary, a matched whole-segment buffered holdout, a paired spatial confidence interval against the same-protocol best, and both full-registry checks in the required order. Any missing evidence is a stop, not a request for human geological inspection.

02

Validate the exact GeoTIFF bytes

The shared writer and an automatic read-back must verify one float32 band, finite predictions within [0,1] inside the footprint, and CRS, dimensions and geotransform matching the authorized sample. The official description specifies null/NaN outside training bounds; encoding and masking must be reconciled with that sample and organizer guidance. Do not silently clip, replace invalid values or assume a zeros-only variant was accepted.

03

Run the separate slot selector

Verify the current account’s remaining allowance and select only a gate-passing candidate. The rules PDF describes up to three feedback submissions per week; the actual allowance is unknown here. The experimental lane itself does not select or spend a slot.

04

Upload on DrivenData

Sign in to the competition, open New submission, select the cleared single-band .tif (or a ZIP containing only that TIFF), and paste the run card’s distinct note of at most 140 characters. The filename identifies the file; the displayed form describes an optional note, not a separate submission-name field.

05

Keep the receipt and final documentation

Record the actual submission-page score, timestamp, exact file SHA-256, name and note together. Only this is an organizer-confirmed score for that file. The rules require one final prediction for both prize rounds and disclosure of generative-AI use in the narrative.
