Mechanism audit

Why might GEMSDOE32 have improved?

What is actually verified

The H33-B2 mask is exactly site31_base & (distance_to_catalogue > 2). The base has 40,199 dots, the result 37,654: 2,545 removed, none added. Its file SHA256 matches the pinned public mirror.

Inspect original code ↗

The arithmetic and mask identity are locally measured, not organizer scoring evidence.

What remains a hypothesis

Removing predictions with little credit for hidden new faults could reduce weighted false-positive mass while retaining recall. But nearness to an existing fault does not make a dot automatically false: a new nearby splay could earn credit.

Without hidden truth or a submission-page receipt, the reported 0.2778 is not a verified causal result, and it does not calibrate a forecast for a new method.

Can we exceed the reported 0.2778? Not by copying or re-pruning it: every file at or above 0.24 in the nine focus sites is the same field. This session built a different field (H-KDAM) and measured it against that field on the same folds with the same emission: 0.1471 vs 0.1011 HOLDOUT-DTI. That is a measured field gain; whether it transfers to the live board is unproven, because this holdout is not rank-correlated with live scores. Owner-reported highs (0.3195, 0.4413) are OWNER-REPORT; the public leaderboard leader read on 2026-10-31 is 0.4544.
