What remains a hypothesis

Removing predictions with little credit for hidden new faults could reduce weighted false-positive mass while retaining recall. But nearness to an existing fault does not make a dot automatically false: a new nearby splay could earn credit.

Without hidden truth or a submission-page receipt, the reported 0.2778 is not a verified causal result, and it does not calibrate a forecast for a new method.

Can we exceed the reported 0.2778? This session's answer: only with a better field at ~40k dots. The shared fail-closed writer refuses NaN, infinities, negative values and values above one; it reopens the written TIFF and the one-TIFF ZIP and validates them before exposing outputs. The earlier portal error “Predicted values must be in range [0, 1]” is what NaN-outside (“-nan”) files trigger — the shipped file writes explicit zeros everywhere outside the footprint and has no NaN on the whole grid.
