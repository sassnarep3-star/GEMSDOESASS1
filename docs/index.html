The decision path

Format is necessary. It isn't enough.

Scientific merit, uniqueness and an uploadable file are separate checks. A code merge is not a submission approval.

01 / Scientific signal

BGAC-1 did not improve

Signed gravity–basement gradient opposition underperformed the strongest same-run feature ablation. AUC canaries did not flag a leak; that does not establish absence of leakage.

02 / Literal novelty

A lattice blocks the lane

An existing 5 px lattice is within 3 px of 99.87% of the footprint. It captures every final BGAC-1 dot under the overlap rule. No density exemption was applied.

03 / Release decision

No file, no weekly slot

The mandatory protocol says stop on duplication. The project does not fabricate a new TIFF, score, validator receipt or download link after a failed gate.
