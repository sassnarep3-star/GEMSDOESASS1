## Decision first

**No candidate was run and no TIFF was generated in this pass.** The frozen H-PBSC run card is negative; `knowledge/NEXT_STEPS.md` says stop until the 13gems calibration-lattice novelty policy is explicitly resolved. Every proposed candidate would still face the same measured 99%+ 3-pixel lattice overlap if emitted as a competitive-size dot raster. The project protocol forbids bypassing that gate or making a private exception. Thus this is a research slate, not a submission recommendation; no slot is to be spent.

The rank is a qualitative *priority* (expected usefulness for recovering withheld surface-scarp labels per implementation cost), not a numeric leaderboard prediction. The labels are lidar-mapped surface scarps, so hypotheses targeting deep/buried geothermal systems have weak direct label alignment. No new external layer is proposed: all layers named below are described in the checked-in cached feature inventory / prior experiment records. This avoids representing unavailable external data as obtainable.
