   2026-10-30 thermal file, so every new TIF in `docs/downloads` failed the check. It is now *hash-locked*:

   approves its own file must agree with its own gate table.

   changed, so the post-review map is extended with `post_review_2026-10-31_implementation_sha256` and a scope

## Pass 3 — the site as a reader sees it

- The executive summary opens with **download first**, then the verdict, then the gate list, then the
  per-site table (file / estimated score / uniqueness / submit decision) — the order the brief asks for.
- Three scope disclosures render on the page: the **lattice** overlap (99.96 %, exempt, and why counting it
  would sink every dotted file including the champion), the **nine-site registry scope**, and the
  **eligibility** caveat.
- Score labels are enforced by tests: `HOLDOUT-DTI` for measured numbers, `OWNER-REPORT` for the supplied
  live scores, and the estimate cell explicitly says it is a projection, not a forecast. The public
  leaderboard leader read on 2026-10-31 is 0.4544 — the user's 0.4413 / 0.3195 figures are owner-reported.
- Historical negatives (SWGB, H-PBSC, BGAC-1) stay on every page, and the download index says
  `withdrawn` / `ok_to_submit = false` for them.

## What remains open (not fixed here)

1. **Eligibility** (rules §1.3) is unconfirmed for the owner account — the single blocker that matters before
   an upload. Nothing in this repository can resolve it.
2. **Sibling-site registry scope**: GEMSDOE44–92 / WBG / KANLER / GINNY / karage / apart are still outside the
   pinned registry, so "unique" is unique *within the nine focus sites and their public mirrors*.
3. **The 70 % / 3 px rule versus the lattice** is a policy question for the organizer, not something to
   reinterpret locally. AMEND-LATTICE-01 is disclosed on every page rather than assumed.
4. **The holdout is not a leaderboard forecast** (ρ = −0.08 over 17 rasters, and it inverts the prune effect).
   No live score is projected from it anywhere in the site or the evidence.
