## Frozen H-PBSC experiment

- Evaluator: `GEMSASS1-HR-v2-segment` (shared `src/gems/holdout.py`). Catalogue features are not used in the field; visible-fault masking is pixel-exact via `fd.active`.
- DTI: α=0.2, β=0.8, 300 m triangular kernel, pooled over 5 whole-segment folds, 95 % tile-bootstrap CI.
- Emission: Poisson-disk, 2.8 px, n=37,654 (champion live budget). Holdout emission on `fd.active` only (must not prune withheld truth). Shipped emission additionally excludes 6 px (600 m) from the **full** published catalogue.
- Canary: each input layer alone on fold-0 withheld truth; AUC > 0.90 → stop.
- Uniqueness vs 17 focus-site rasters **plus** this repo's prior SWGB file and GEMSDOESASS2/3 shipped files. Lattice calibration raster (13gems, 99.87 % of footprint) is logged as IR-LATTICE-01 and is **not** treated as a competing submission (same policy as the SWGB lane; treating it as one makes the 70 % rule vacuous).
- Bar to beat for `promote`: HOLDOUT-DTI of un-pruned 0.2600 family base = **0.1011 [0.0956, 0.1072]** (`evidence/swgb/holdout_calibration.json`). Current repo holdout-best is SWGB 0.1401 (different lane, already shipped). A new unique TIF is written if uniqueness + validator pass; `promote` requires beating the 0.1011 bar. A projection is never a score.
- Budget: ≤3 experiments, ≤2 hours. E1 = H-PBSC. E2 = no-mag ablation (same lane). E3 = emission n∈{37654,44090} only if E1 or E2 beats the bar.
- Non-fault mimic: pluvial Lake Lahontan shorelines and wave-cut benches (coherent, low-relief, playa-bounding, usually **no** magnetic edge). Canal banks and terrace risers.
