## Frozen gates for an actually assigned lane

1. Use the agreed cached feature stack and shared template's `evaluate_holdout.py` and `submission_writer.py`; do not fork their metric or writer. **Two different template lineages are documented** ([GEMSDOE24 contract](https://github.com/buffedlizard55-lab/GEMSDOE36/blob/61783525af4aa6dcf8da0bc68b06fa38b89ed27a/registry/template_pins.json) and [57GEMSDOE pin](https://github.com/buffedlizard55-lab/GEMSDOE31/blob/abd9a45cc7adf046d7d3829eb6e8c980943f462d/registry/shared_template.json)). No template is uniquely specified in this checkout; choose one explicitly before experiments. If a shared tool is wrong, repair it upstream once and record the correction.
2. Hide whole fault segments with a buffer, derive *all* catalogue-based inputs only from visible labels, mask visible fault pixels exactly, and pool the official-formula DTI with α=0.2, β=0.8 and a 300 m triangular kernel. A connected-component segment proxy is not a verified geological segment ID.
3. Test every feature alone, including both AUC polarities, for leakage; AUC >0.90 stops the run. Check the pre-placement surface against the complete pinned registry before any dots, then final dots against the same registry. Missing, malformed, stale or unaligned registry entries are not passes.
4. Compare the fixed candidate against the current **same-evaluator** holdout best with a paired spatial-block 95% CI. Do not use cross-evaluator rankings or a proxy-to-leaderboard conversion as an estimate.
5. Read back the actual file; verify one float32 band, exact sample grid and range, and document outside-mask handling. Run a separate selector with the real account quota. A format pass, a changed SHA or a promising proxy alone is never upload authorization.
6. At most three experiments or two hours; no upload in the experiment lane. Record a machine-readable run card even for a negative result.

The pinned lattice covers almost the entire owner-mirror footprint within 3 pixels. Its preflight proves standard-budget placement fails, even before any hypothesis is fit. A smaller dot budget is **not** automatically unique; do not target the few uncovered pixels to game the rule. A changed registry definition or threshold needs explicit authorization, not a quiet exception.
